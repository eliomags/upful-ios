## Equity Breakdown Logic

- **cash_balance**: The portion of total_equity held as uninvested cash (30-60% of total_equity)
- **Remaining equity** (total_equity - cash_balance) is held in open positions (covered by Agent-2b)
- Users 1-5: Power users with accumulated equity well above $25,000 starting amount
- Users 6-12: Mid-tier users, moderate gains
- Users 13-20: Mixed results, some gains, some losses
- Users 21-25: Newer users, close to starting equity
- User 26 (benH): Was banned then unbanned, equity took a hit ($23,000)
- User 28 (willt): Consistently negative PnL ($21,000)
- User 29 (charlottew): Always resets each month, exactly $25,000

## Validation Queries

```sql
-- Verify all 30 portfolios inserted
SELECT COUNT(*) AS portfolio_count FROM portfolios WHERE competition_month = '2026-02';
-- Expected: 30

-- Verify all are active
SELECT COUNT(*) AS active_count FROM portfolios WHERE is_active = 1 AND competition_month = '2026-02';
-- Expected: 30

-- Verify cash_balance is between 30-60% of total_equity for all
SELECT id, user_id, cash_balance, total_equity,
       ROUND(cash_balance * 100.0 / total_equity, 1) AS cash_pct
FROM portfolios
WHERE competition_month = '2026-02'
ORDER BY total_equity DESC;

-- Verify edge cases
SELECT p.id, u.username, p.cash_balance, p.total_equity
FROM portfolios p
JOIN users u ON u.id = p.user_id
WHERE u.username IN ('charlottew', 'willt', 'benH')
AND p.competition_month = '2026-02';
-- Expected:
--   charlottew: total_equity = 25000.00 (always resets)
--   willt:      total_equity = 21000.00 (negative PnL)
--   benH:       total_equity = 23000.00 (banned/unbanned)

-- Verify implied position market value (total_equity - cash_balance)
SELECT id, user_id, total_equity, cash_balance,
       ROUND(total_equity - cash_balance, 2) AS implied_positions_value,
       ROUND((total_equity - cash_balance) * 100.0 / total_equity, 1) AS invested_pct
FROM portfolios
WHERE competition_month = '2026-02'
ORDER BY total_equity DESC;

-- Verify no duplicate user_ids in the same competition month
SELECT user_id, COUNT(*) AS cnt
FROM portfolios
WHERE competition_month = '2026-02'
GROUP BY user_id
HAVING cnt > 1;
-- Expected: 0 rows
```
