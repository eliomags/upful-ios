   - Web rebuild may use different services or Firebase Web SDK

   - iOS has StoreKit-based IAP with premium features
   - Web needs Stripe or similar payment processor

4. Push Notifications
   - iOS has APNs-based notifications
   - Web needs Web Push API or service worker notifications

5. Stock Suggestions/Recommendations
   - iOS has SuggestionFeedViewController with stock recommendations
   - Web prototype has basic "Recommended" section but no algorithm
