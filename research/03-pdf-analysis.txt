### Feature 1: User Registration / Onboarding

**Required fields:**
- Username
- Profile Picture
- PayPal email (for prize payouts)
- Password (account security)

**Tier selection at signup:**
- Free version: Does not allow monthly payouts
- Paid version: $6.99/month subscription

**Payout structure:** All payouts are monthly. They are an aggregate of the user's daily positions, weekly positions, and monthly positions.

**Subscription prompt:** If the user selects the subscription, a "Thank You for Subscribing, we wish you happy trading" confirmation screen appears. Subscribing also gives the user a chance to win $100 every month. If the user selects the free version, they go directly to the home page (portfolio view).

### Feature 3: Leaderboard

**Access:** Both FREE and PAID users can view the leaderboard.

**Privacy:** Users cannot see each other's exact portfolio holdings -- only percentage growth from the initial $25,000 and total portfolio value.

**Displayed information per user:**
- Username
- Profile picture
- Position/rank number
- Percentage growth (e.g., +09%)
- Current portfolio value
- Prize amount (displayed next to top winners, e.g., $100, $75, $50)

**Time filters:** Daily, Weekly, Monthly, Quarterly (3 months), and 6 months. Top 100 users shown for each timeframe.

**Line graph:** Reflects the user's portfolio percentage fluctuation over time.

**Two tabs on the leaderboard:**
- "Subscribed" tab: Shows all paying subscribers ranked
- "Free" tab: Shows only free users ranked

**Free user feature:** The Free tab displays a special feature showing how much a free user COULD have made if they had paid for the subscription. It mirrors the subscribed leaderboard structure but only includes free users and shows what their payout would have been (a conversion/upsell mechanism).

7. Track portfolio growth
8. Win real prize money if you place in the top 100 in daily, weekly, monthly, and quarterly contests

### SUMMARY OF KEY STRATEGIC INSIGHTS ACROSS BOTH DOCUMENTS

**Transformation Journey:**
- The app was originally called "Upful: Simple Paper Trading" -- a basic virtual stock trading app
- It is being rebranded to "Jyanik"
- The core transformation is from a simple paper trading simulator into a gamified competition platform where users trade with virtual money but win real cash prizes

**Business Model (4 Revenue Streams):**
1. Subscription: $6.99/month (primary revenue driver)
2. Group fees: $20 per group
3. Advertising revenue
4. In-app purchases: $2.99 for additional $25K virtual cash (from Features Guide)

**Monetization Strategy:**
- Freemium model with aggressive upsell tactics (showing free users what they "missed out on")
- Premium features gated behind subscription (chat/social hub, actual payouts)
- In-app purchases for budget replenishment
- Future: selling curated portfolios from top performers, AI/ML data products for brokerage firms

**Key Metrics/KPIs:**
- Total Addressable Market: $1.025B
- Current users at time of deck: 3,000 downloads
- Year 1 target revenue: $290K
- Year 2-3 cumulative target: $3.78M
- Monthly prize payout budget: ~$15,103
- Series A targets: $24M valuation, $5M raise, $200K/month revenue
- Target conversion rates: 10% free, 5% paid

**Technical Stack (inferred):**
- iOS native app (App Store)
- iEXTrading API (real-time stock data)
- Intrinio API (financial data/metrics)
- PayPal (user payouts)
- Stripe (direct transfers)
- Cloud storage for API data
- Future: AI/ML, blockchain
